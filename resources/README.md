# Resources

## Contents

### `contribution-workflow.md`

A practical workflow for identifying, planning, and completing daily contributions.

### `git-setup-workflow.md`

Basic Git and GitHub setup instructions, including common workflows used in open source projects.

### `learning-resources.md`

A curated collection of articles, courses, tools, and references for learning open source development and collaboration.

### `oss-contribution-playbook.md`

A practical guide to understanding modern open source contribution, finding projects, interacting with maintainers, and building long-term involvement.

## Purpose

These resources are intended to support consistent learning, contribution, and skill development throughout the challenge. They can be used as a starting point for anyone interested in open source participation, regardless of experience level.
